## Purpose

This empty template records the composition of the practitioner incident register so the evidence base can be reviewed for balance, limitations and selection effects.

The composition log is mandatory, dated and reviewable.

**Control:** At least one unnecessary-escalation / simple-resolution / routine case should be sought for approximately every three dramatic cases, where such evidence is available.

## Review Warning Triggers

Record a warning if any of the following appears to be true:

- dramatic cases materially outnumber routine cases without explanation;
- escalation cases materially outnumber simple-resolution cases without explanation;
- specialist handoff is over-represented relative to ordinary boundary recognition;
- records with weak documentation dominate the set;
- success stories dominate and adverse, ordinary or ambiguous cases are absent.
