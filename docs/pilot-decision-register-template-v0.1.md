# Pilot Decision Register Template — v0.1

**Status:** WORKING DRAFT

**Prepared by:** Carpenters for Housing Reform Victoria
**Version:** 0.1
**Date:** August 2026

---

## Purpose

This register records all governance decisions made in relation to the ARC capability-assessment pilot. It supports audit, accountability and review.

Every significant governance decision must be recorded here. Operational day-to-day activities do not need to be recorded unless they involve a decision affecting eligibility, assessment, privacy, safety, or governance integrity.

---

## Decision Categories

| Code | Category |
|---|---|
| RECRUITMENT | Decisions relating to recruitment channels, messaging or processes |
| ELIGIBILITY | Decisions relating to individual applicant eligibility |
| ASSESSOR_ASSIGNMENT | Decisions assigning assessors to candidates |
| CONFLICT | Conflict of interest determinations and outcomes |
| EVIDENCE | Decisions about evidence acceptance, rejection or interpretation |
| CALIBRATION | Decisions arising from assessor calibration or moderation |
| ASSESSMENT | Decisions affecting individual assessment outcomes or processes |
| PRIVACY | Decisions about data handling, sharing, retention or breach response |
| SAFETY | Decisions in response to safety concerns or incidents |
| COMPLAINT | Decisions arising from complaint processes |
| PAUSE_STOP | Decisions to pause, narrow, redesign or stop the pilot |
| FRAMEWORK_CHANGE | Decisions to amend the assessment framework or governance documents |

---

## Register Fields

Each decision record must include:

| Field | Description |
|---|---|
| Decision ID | Unique identifier (e.g. DEC-001) |
| Date | Date of decision |
| Category | One of the decision categories above |
| Decision | Clear description of the decision made |
| Reason | Why this decision was made |
| Evidence relied upon | Sources or information informing the decision |
| Decision-maker | Name and role of the person(s) making the decision |
| Conflicts declared | Were conflicts declared before the decision? What was the outcome? |
| Alternatives considered | What other options were considered? |
| Affected participants | Participant IDs of affected persons (if applicable) |
| Review required | Is this decision subject to scheduled review? Yes / No / Date |
| Status | ACTIVE / SUPERSEDED / UNDER_REVIEW / CLOSED |
| Follow-up | Any required follow-up action, owner and due date |

## Notes on Use

- Decision IDs are assigned sequentially (DEC-001, DEC-002, etc.).
- A SUPERSEDED status means the decision has been replaced by a later decision. The original entry is retained.
- All PAUSE_STOP decisions must be recorded here regardless of whether the pilot is subsequently resumed.
- Conflict declarations must be noted against any decision where a conflict was considered.
- Decisions that affect individual participants must use Participant IDs, not full names.
