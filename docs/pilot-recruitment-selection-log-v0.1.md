## Purpose

This log records the recruitment and selection activity for the ARC capability-assessment pilot. It supports audit, accountability and bias review.

All selection decisions must use controlled reason codes. Subjective labels such as "not suitable" must not be used.

## Selection Reason Codes

| Code | Meaning |
|---|---|
| ELIGIBLE_SELECTED | Meets all inclusion criteria; selected for pilot cohort |
| ELIGIBLE_WAITLISTED | Meets all inclusion criteria; placed on waitlist due to cohort capacity |
| EVIDENCE_GAP | Eligibility evidence incomplete or insufficient |
| NOT_YET_ELIGIBLE | Does not currently meet eligibility threshold |
| UNABLE_TO_VERIFY | Evidence provided cannot be verified |
| CONFLICT | Conflict of interest prevents participation |
| COHORT_BALANCE | Eligible but cohort balance requirements already met in this category |
| WITHDRAWN | Applicant withdrew during the process |
| OTHER_RECORDED_REASON | Other reason, recorded in the notes field and Decision Register |

Reason codes must be recorded for every applicant. Codes must be applied consistently. Where OTHER_RECORDED_REASON is used, the reason must be documented in the log notes and cross-referenced with a Decision Register entry.
