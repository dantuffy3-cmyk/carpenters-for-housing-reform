# ADR-005: Practitioner function before regulatory vehicle

## Status

Proposed

## Context

The initiative has already adopted a capability-first architecture. A further governance refinement is needed so government-facing sequencing is explicit:

- practitioner function;
- capability definition;
- assessment reliability;
- calibration consistency;
- public-interest evaluation; and
- statutory vehicle selection (if any).

Without this sequencing, implementation-vehicle discussions can be mistaken for predetermined policy outcomes.

## Decision

The initiative evaluates the existence of a distinct practitioner function before determining capability recognition or statutory vehicle.

## Rationale

This improves alignment with capability-first governance and Victoria’s enhanced registration design principles while preserving government discretion.

## Consequences

### Positive

- clarifies that RRC is one option, not a predetermined outcome;
- improves policy neutrality in government-facing material;
- preserves DB-L reform, credential-only and alternative mechanisms as serious options;
- preserves no-formal-recognition as a valid evidence-based outcome.

### Trade-offs

- requires controlled wording updates across canonical documents;
- requires ongoing governance checks to avoid reintroducing vehicle-first language.
