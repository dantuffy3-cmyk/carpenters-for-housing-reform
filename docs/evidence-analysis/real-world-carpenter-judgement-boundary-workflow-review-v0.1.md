## Controlling Question

> In real residential renovation, alteration, repair and existing-building workflows, is there independent evidence that carpenters themselves exercise professional judgement or boundary-recognition decisions beyond technical participation or reporting upward?

## Part 1 — Workflow Stage Decomposition

The residential renovation workflow is decomposed into twelve stages. Actors are mapped for each stage. No single-actor answer is assumed.

| Stage | Code | Description |
|---|---|---|
| 1 | PRE_WORK_REVIEW | Review of plans, specifications, site conditions and scope before work commences |
| 2 | OPEN_UP / DEMOLITION | Removal of cladding, linings, floor coverings, fixtures to expose existing structure |
| 3 | CONDITION_DISCOVERY | Identification of concealed or unexpected conditions revealed by opening-up |
| 4 | INTERPRETATION | Assessment of observed conditions against original scope and technical requirements |
| 5 | DECISION_TO_CONTINUE | Judgement that conditions are consistent with scope and continuation is appropriate |
| 6 | DECISION_TO_STOP | Judgement that continuation is unsafe, technically unsound or outside scope authority |
| 7 | SCOPE_CHANGE | Revision of work scope following changed conditions |
| 8 | SPECIALIST_TRIGGER | Recognition that specialist input (engineering, surveying, trades, hazard) is required |
| 9 | REFERRAL / ESCALATION | Formal communication to builder, supervisor, engineer, surveyor or licensed trade |
| 10 | RESEQUENCING | Adjustment of work sequence following discovered conditions |
| 11 | DOCUMENTATION | Recording of discovered conditions, decisions and responses |
| 12 | HANDOFF / RETURN_TO_WORK | Resumption of work after specialist input, scope revision or regulatory clearance |

### Actor mapping by stage

| Stage | Who observes | Who interprets | Who decides | Who has authority | Who communicates | Who refers/escalates |
|---|---|---|---|---|---|---|
| PRE_WORK_REVIEW | Carpenter / supervisor / builder | Builder / supervisor (with designer input) | Builder / supervisor | Builder (statutory) | Supervisor to team | Supervisor/builder to engineer or surveyor where required |
| OPEN_UP / DEMOLITION | Carpenter | Carpenter (initial) / supervisor | Supervisor / builder | Builder (statutory) | Carpenter reports to supervisor | Supervisor/builder |
| CONDITION_DISCOVERY | Carpenter (first on site) | Carpenter (initial observation) / supervisor | Supervisor / builder | Builder (statutory) | Carpenter reports to supervisor | Supervisor/builder → engineer / surveyor |
| INTERPRETATION | Supervisor / builder | Builder / engineer (where structural) | Builder / engineer / surveyor | Builder / engineer / surveyor | Builder/supervisor to all parties | Builder → engineer/surveyor where required |
| DECISION_TO_CONTINUE | Builder / supervisor | Builder / engineer (where required) | Builder / supervisor | Builder (statutory) | Supervisor to site | Builder to surveyor where amended permit required |
| DECISION_TO_STOP | Carpenter / supervisor | Supervisor (immediate) / builder | Builder / supervisor (immediate); carpenter for generic safety stop | PCBU / builder (statutory) | Supervisor to site | Supervisor/builder to engineer/surveyor/licensed trade |
| SCOPE_CHANGE | Builder / supervisor | Builder / designer / engineer | Builder | Builder (statutory) | Builder to owner and surveyor | Builder → surveyor (permit amendment) |
| SPECIALIST_TRIGGER | Carpenter (observation) / supervisor | Supervisor / builder | Builder | Builder / engineer / surveyor | Builder/supervisor to specialist | Builder to specialist |
| REFERRAL / ESCALATION | Supervisor / builder | Builder | Builder | Builder (statutory); surveyor (permit) | Builder to specialist / owner / surveyor | Builder |
| RESEQUENCING | Supervisor / builder | Builder / engineer | Builder | Builder | Supervisor to site team | — |
| DOCUMENTATION | Carpenter / supervisor | Supervisor / builder | Builder | Builder | Supervisor → builder → regulatory system | — |
| HANDOFF / RETURN_TO_WORK | Builder / supervisor | Builder | Builder | Builder / surveyor (where permit required) | Supervisor to site | — |

**Notes on this mapping:**

- Carpenter frequently occupies the OBSERVING position in CONDITION_DISCOVERY.
- Carpenter does not hold statutory authority at any stage.
- Generic safety stop (DECISION_TO_STOP — immediate unsafe condition) is assigned at worker level under WHS legislation; this is not a technical-scope or boundary decision.
- Staged escalation is normal: carpenter observes → reports → supervisor decides → builder acts.

## Part 3 — Carpenter-Specific Actor Language

This part searches for explicit actor wording identifying carpenters in real-world sources.

### Classification key

| Code | Meaning |
|---|---|
| DIRECT_CARPENTER_JUDGEMENT | Source explicitly assigns independent judgement decision to carpenter |
| DIRECT_CARPENTER_PARTICIPATION | Source explicitly requires carpenter action but within a wider decision framework |
| CARPENTRY_CONTEXT_ONLY | Source refers to carpentry work type but does not assign specific judgement function |
| SHARED_ROLE | Decision shared across multiple actors including carpenter |
| OTHER_ACTOR | Source assigns function to a non-carpenter actor |
| UNKNOWN | Source does not allow attribution |

### Findings

| Source | Actor language found | Classification | Limitation |
|---|---|---|---|
| CPC30220 (performance evidence) | Carpenter must check materials and components meet specifications; identify and report damaged or defective materials | DIRECT_CARPENTER_PARTICIPATION | Checking and reporting within a supervised context; not independent boundary authority |
| CPCCCA3025 | Carpenter must read and interpret plans, identify discrepancies, report discrepancies to supervisor | DIRECT_CARPENTER_PARTICIPATION | Explicit upward reporting expected; decision authority not assigned to carpenter |
| CPCWHS3001 | Worker must identify hazards, assess risk, select and apply controls, report to supervisor/PCBU where required | DIRECT_CARPENTER_PARTICIPATION | Generic WHS duty — not carpentry-specific or renovation-specific judgement |
| CPC40120 | Leading hand/supervisor reads plans, coordinates trades, resolves site-level issues, communicates with builder | DIRECT_CARPENTER_PARTICIPATION (at supervisor level) | CPC40120 is a supervisor qualification, not an occupational carpenter qualification |
| ANZSCO 3312 | Task descriptions include: assembles and erects framework, installs prefabricated components, repairs and replaces structural elements, fits door and window frames | CARPENTRY_CONTEXT_ONLY | Task descriptions do not address judgement, boundary or stop decisions |
| WorkSafe Victoria demolition guidance | Worker must cease work if exposed to serious risk; PCBU must ensure safe design of work processes | SHARED_ROLE | Safety duty attaches to all workers; separate from technical-scope or boundary decision |
| Safe Work Australia | Person conducting a business or undertaking (PCBU) has primary safety duty; worker has duty to report unsafe conditions | SHARED_ROLE | Stop-work right attaches to worker level for genuine safety risk; does not confer technical-scope authority |
| BPC domestic builder guidance | Registered domestic builder holds statutory responsibility for domestic building work; supervises all trades on site | OTHER_ACTOR | Builder is the primary statutory actor for scope and boundary decisions |
| VCAT Narrayen v Emperor Homes [2025] | Multiple experts and builder involved in defect causation; no carpenter identified as independent decision-actor | OTHER_ACTOR | CASE_EVIDENCE_ONLY — case does not isolate carpenter judgement |
| HIA renovation guide | Site supervisor and builder coordinate scope changes; trades notify supervisor of unexpected conditions | OTHER_ACTOR / SHARED_ROLE | Builder/supervisor dominant; trades occupy observing/reporting role |

**Summary finding — Part 3:**

No source reviewed directly assigns independent judgement, boundary-recognition authority, or stop/refer authority to a carpenter as a distinct statutory or professional role.

Carpenter participation, checking, reporting and WHS stop duties are evidenced.  
Independent carpenter boundary authority is **not evidenced** by direct actor language in sources reviewed.

**Finding — Part 4:**

The **observation** role in condition discovery frequently falls to the person working on that area of the site, which may be a carpenter. This is consistent with DIRECT_CARPENTER_PARTICIPATION.

The **interpretation and decision** roles are assigned to the builder, engineer, surveyor or licensed trade depending on the nature of the condition. Carpenters are not assigned independent interpretation or decision authority in any source reviewed.

The question "Who is expected to recognise that the original scope can no longer safely or reliably continue?" is answered in available sources by the builder (statutory) and engineer/surveyor (specialist) — not the carpenter as an independent authority.

## Part 5 — Technical Stop and Withhold

### Stop-type classification

| Stop type | Definition | Actor in sources reviewed |
|---|---|---|
| GENERIC_WHS_STOP | Worker ceases because of immediate serious safety risk | Worker/PCBU under WHS legislation — attaches to all workers including carpenter |
| TECHNICAL_STOP_UNDER_UNCERTAINTY | Work withheld pending technical clarification, additional information or specialist determination | Builder / supervisor — no direct carpenter-specific evidence found |
| STATUTORY_STOP | Work stopped by order of a regulator, surveyor or safety authority | Building surveyor / WorkSafe / BPC — not carpenter authority |
| BUILDER_SUPERVISOR_STOP | Work suspended pending builder/supervisor decision on scope | Builder / supervisor |
| CARPENTER_INDEPENDENT_STOP | Carpenter independently ceases work on technical grounds without instruction | NOT EVIDENCED — no source directly establishes this as a carpenter-specific authority |

### Key distinctions

| Claim | Evidence status |
|---|---|
| Work withheld due to insufficient technical information | Attributed to builder/supervisor in sources reviewed |
| Work stopped pending engineering | Builder acts; engineer/surveyor determines |
| Work stopped pending builder/surveyor decision | Builder/supervisor — not carpenter |
| Scope suspended after concealed conditions revealed | Builder — sometimes reported by worker (including carpenter) |
| Further investigation required before continuation | Builder directs further investigation; specialist performs it |

**Finding — Part 5:**

GENERIC_WHS_STOP is evidenced at worker level including carpenter. Safe Work Australia and WorkSafe Victoria materials confirm this.

TECHNICAL_STOP_UNDER_UNCERTAINTY, STATUTORY_STOP and BUILDER_SUPERVISOR_STOP are assigned to builder/supervisor/regulatory actors in sources reviewed. No source directly evidences a CARPENTER_INDEPENDENT_STOP as a distinct technical-scope authority separate from WHS duty.

The distinction between a safety stop and a technical-scope stop remains important. The presence of WHS-based stop duties does not establish independent technical boundary authority.

| Waterproofing practitioner | Builder / supervisor | Builder | Builder | Builder | Builder | — |
| Other specialist | Various | Various | Various | Builder | Builder | — |

**Finding — Part 6:**

Carpenters may occupy the OBSERVES_CONDITION and RECOGNISES_POSSIBLE_NEED stages in some specialist-trigger situations as the person on site when a condition is discovered.

REPORTS_CONDITION is attributed to the carpenter where the carpenter is first to observe; the report is directed to supervisor or builder (consistent with CPCCCA3025 reporting-to-supervisor requirements — L2).

DECIDES_SPECIALIST_INPUT_IS_REQUIRED and AUTHORISES_THE_SPECIALIST_ENGAGEMENT are consistently assigned to builder, supervisor, licensed trade or specialist in sources reviewed. These stages are not attributed to carpenters in any source reviewed.

No source directly establishes that a carpenter independently DECIDES that specialist input is required and AUTHORISES the engagement without reference to the builder or supervisor.

Carpenter attribution at this workflow stage: OBSERVES_CONDITION (L2) — RECOGNISES_POSSIBLE_NEED (L2 to L3 boundary; recognition competence evidenced, independent decision not established) — REPORTS_CONDITION (L2) — DECIDES and AUTHORISES (NOT_ATTRIBUTED_TO_CARPENTER).

## Part 10 — Authority Versus Competence

| Distinction | Analysis |
|---|---|
| ABILITY_TO_RECOGNISE | Carpenters are trained to identify defective materials, report discrepancies, and apply hazard identification — competence for recognition is evident in training sources |
| AUTHORITY_TO_DECIDE | No source directly assigns carpenters authority to make the technical scope, continuation or referral decision as an independent actor |
| AUTHORITY_TO_DIRECT_OTHERS | Builder authority under the Building Act 1993 (Vic) and Domestic Building Contracts Act 1995 (Vic) rests with the registered builder, not the carpenter |

A carpenter may need, and may acquire through experience, competence to recognise a problem before the formal decision-holder acts. This recognition function may be practically important without conferring authority.

**This distinction is central and is maintained throughout this review.**

Competence to recognise is not authority to decide.  
Authority to decide is not evidenced in carpenter-specific sources reviewed.

## Part 19 — Falsification

Each proposition is tested against available evidence.

### Proposition 1: Carpenters exercise independent technical judgement

**Falsification attempt:** Sources do not assign independent technical judgement to carpenters as a formal or statutory role. CPCCCA3025 explicitly requires carpenters to report discrepancies to supervisors. Building Act 1993 assigns statutory authority to builders. No source reviewed directly contradicts this framing.

**Outcome:** Proposition NOT ESTABLISHED. Upward reporting model dominates available sources.

---

### Proposition 2: Carpenters independently stop work under technical uncertainty

**Falsification attempt:** WHS legislation provides a stop-work right for immediate safety risk. This attaches to all workers including carpenters. No source assigns an additional technical-scope stop right to carpenters independently of builder/supervisor authority.

**Outcome:** Generic WHS safety stop is evidenced. Technical-scope independent stop is NOT ESTABLISHED.

---

### Proposition 3: Carpenters independently trigger specialist referral

**Falsification attempt:** Training sources require carpenters to report to supervisors. HIA and MBA guidance assigns specialist engagement to builder/supervisor. No source assigns carpenter-independent specialist authorisation.

**Outcome:** Observing triggers and reporting upward is evidenced. Independent authorisation is NOT ESTABLISHED.

---

### Proposition 4: Experienced carpenters have higher judgement autonomy

**Falsification attempt:** Public regulatory and occupational sources do not formally distinguish experienced carpenters from other carpenters in terms of authority. CPC40120 distinguishes supervisor level but this is a separate qualification.

**Outcome:** Experience effect is NOT FORMALLY ESTABLISHED in public sources reviewed. PRACTICALLY_INDICATED at supervisor-qualification level only.

---

### Proposition 5: Real-world workflow supports L3

**Falsification attempt:** No source reviewed directly assigns independent judgement authority to carpenters. The strongest evidence (training) is consistent with L2 participation and upward reporting.

**Outcome:** L3 NOT DIRECTLY SUPPORTED by evidence reviewed. L3 remains a highest-plausible level but is not directly established.

---

### Proposition 6: Real-world workflow supports L4

**Falsification attempt:** Recognition competence is evidenced (training). Boundary/refer/stop authority is assigned to builder/supervisor/specialist in sources reviewed. No source assigns this to carpenters independently.

**Outcome:** L4 NOT DIRECTLY SUPPORTED. L4 remains possible given recognition competence but is not established by direct actor-language evidence.

---

### Proposition 7: DB-L/builder roles do not fully explain the decisions

**Falsification attempt:** DB-L and builder roles are the formally assigned decision actors in public sources. Builder holds statutory authority; DB-L registration implies boundary-awareness as part of scope. No source creates a function gap that carpenters uniquely fill with formal authority.

**Outcome:** DB-L/builder roles are the most plausible formal explanation for L3/L4-type functions in sources reviewed. The proposition is NOT ESTABLISHED — builder/DB-L roles do explain the formal decision layer.

---

### Proposition 8: Real-world evidence strengthens ARC distinctiveness

**Falsification attempt:** This review does not find evidence that strengthens Canonical ARC beyond the current C/45% position. No L3 or L4 direct evidence was found. L2 participation is confirmed but does not establish functional distinctiveness.

**Outcome:** Canonical ARC C/45% is NOT strengthened by this review.
