# DB-L Judgement & Boundary Recognition Evidence Review

**Version:** 0.1

**Scope:** Public-evidence review focused only on whether current DB-L Carpentry assessment is publicly evidenced to evaluate judgement, scope limits, referral/escalation and boundary recognition.

## Purpose Notice

This is a governed evidence review addressing one controlling question:

> What does current public evidence show about whether DB-L Carpentry assessment evaluates professional judgement, recognition of scope limits, referral/escalation and boundary recognition in practice?

This is not a general DB-L review, not an ARC advocacy document, and not evidence that DB-L is inadequate.

## Preserved Governed Baseline

**DB-L baseline retained:** **D — Current public evidence is insufficient to determine relationship between DB-L Carpentry assessment and ARC seven-domain model.**  
**Confidence:** **75%**

- Certificate III Carpentry plus prescribed units are relevant.
- Technical Referee evidence is part of the current process.
- DB-L scope includes construction, alteration, renovation and repair within carpentry class scope.
- A DB-L-specific new examination must not be assumed unless directly verified.
