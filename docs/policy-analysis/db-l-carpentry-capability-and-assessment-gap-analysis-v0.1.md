## 1. Purpose

This document tests whether a genuine capability or assessment gap is established within the current Victorian Domestic Builder (Limited to Carpentry) [DB-L Carpentry] framework.

It is not an advocacy document. It does not advocate for RRC or any other regulatory mechanism.

---

## 2. Analytical Discipline

Function first  
→ capability  
→ evidence  
→ existing mechanism  
→ assessment coverage  
→ residual gap  
→ proportionality  
→ mechanism only if justified

Rule:

> **A capability must not be labelled a gap merely because it is not named explicitly. The test is whether it is already adequately captured directly or indirectly.**

Control principle preserved:

> **NOT_CLEARLY_EVIDENCED ≠ capability absent from actual assessment.**

## 3. Current DB-L Carpentry Baseline

### VERIFIED

- DB-L Carpentry is an active Victorian registration class.
- The class provides broad domestic carpentry scope including construction, alteration, renovation and repair within class limits.
- Current registration architecture includes qualification requirements, practical experience, technical referee evidence and suitability assessment.
- Current regulator exam architecture indicates an online exam may apply in rollout context.

### INTERPRETIVE

- Combined qualification, experience and referee architecture may already capture substantial practical and managerial capability signals.

### UNKNOWN

- Publicly available weighting, scoring and pass-threshold detail for DB-L capability assessment depth.
- Full non-public/confidential exam content and assessor practice detail.
- Whether bounded non-statutory escalation judgement is always directly tested or primarily inferred through broader competence evidence.

## 10. Candidate Residual Capability

Current candidate:

> **Bounded Stop / Refer / Escalate judgement in non-statutory-trigger existing-building scenarios.**

Narrow definition:

recognise condition  
→ acknowledge uncertainty  
→ determine whether the matter remains within carpentry competence/authority  
→ cease or control work where necessary  
→ identify correct escalation recipient  
→ document basis  
→ resume only when sufficient evidence/authority exists

Status: this is a **CANDIDATE** assessment gap, not a confirmed gap.
