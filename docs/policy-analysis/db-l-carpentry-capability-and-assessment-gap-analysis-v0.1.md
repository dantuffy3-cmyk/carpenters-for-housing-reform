# DB-L Carpentry Capability and Assessment Gap Analysis — V0.1

**Version:** 0.1  
**Date:** September 2026  
**Status:** WORKING DRAFT — internal evidence-governance analysis

---

## 1. Purpose

This document tests whether a genuine capability gap or assessment gap is established within the current Victorian Domestic Builder (Limited to Carpentry) [DB-L Carpentry] framework.

It is an evidence-governance document only. It does not advocate for a Registered Residential Carpenter pathway or any other regulatory mechanism.

---

## 2. Analytical Discipline

Function first  
→ capability  
→ evidence  
→ existing mechanism  
→ assessment coverage  
→ residual gap  
→ proportionality  
→ mechanism only if justified

Rule:

> **A capability must not be labelled a gap merely because it is not named explicitly. The test is whether it is already adequately captured directly or indirectly.**

---

## 3. Current DB-L Carpentry Baseline

### VERIFIED

- DB-L Carpentry is an active Victorian registration class.
- The class includes substantial domestic carpentry scope including construction, alteration, renovation and repair within class limits.
- Current architecture uses qualification requirements, practical experience, technical referee evidence and registration suitability assessment.
- Public regulator material indicates that an online exam may apply in current reform architecture.

### INTERPRETIVE

- Existing pathway controls likely capture broad practical accountability and project-management signals through combined qualification, experience and referee channels.

### UNKNOWN

- Full public visibility of assessment weighting, scoring thresholds and critical-failure rules.
- Full visibility of implemented DB-L exam content and depth, where content is confidential/not publicly available.
- Whether bounded non-statutory escalation judgement is always tested explicitly or mainly inferred through general competence evidence.

## 10. Candidate Residual Capability

Current candidate:

> **Bounded Stop / Refer / Escalate judgement in non-statutory-trigger existing-building scenarios.**

Narrow functional definition:

recognise condition  
→ acknowledge uncertainty  
→ determine whether it remains within carpentry competence/authority  
→ cease or control work where necessary  
→ identify correct escalation recipient  
→ document basis  
→ resume only when sufficient evidence/authority exists

This is a **CANDIDATE assessment gap**, not a confirmed gap.

## 13. Minimum-Change Ladder

If the residual capability is later confirmed, interventions should be tested in this order:

1. no change  
2. improved guidance  
3. Technical Referee Report refinement  
4. examination/scenario refinement  
5. competency-unit refinement  
6. endorsement within existing class  
7. voluntary advanced credential  
8. DB-L reform  
9. new statutory category

Movement down the ladder should occur only where evidence shows earlier options are insufficient.
