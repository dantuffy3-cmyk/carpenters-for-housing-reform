## Purpose

This index records all documents associated with the Carpenters for Housing Reform Victoria initiative, grouped by purpose. It identifies the current status of each document and provides navigation for government, regulator and industry stakeholders.

Document statuses:

- **CURRENT** — active, reviewed and approved for use in government and stakeholder contexts
- **CONSULTATION DRAFT** — prepared for external review; may change following feedback
- **WORKING DRAFT** — internal working document; not yet approved for broad distribution
- **SUPERSEDED** — replaced by a more recent version
- **HISTORICAL** — an earlier version retained for record purposes
