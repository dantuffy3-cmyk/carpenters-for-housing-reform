# Pilot Participant Register Template — v0.1

**Status:** WORKING DRAFT

**Prepared by:** Carpenters for Housing Reform Victoria
**Version:** 0.1
**Date:** August 2026

---

## Purpose

This register tracks all pilot participants across all categories. It uses Participant IDs to minimise the distribution of sensitive personal information. The link between Participant ID and identity is held separately by the evidence custodian.

---

## Access Controls

This register is maintained by the pilot coordinator and evidence custodian. Access is restricted to authorised pilot personnel as defined in the Privacy and Data Handling Plan (`docs/pilot-privacy-and-data-handling-plan-v0.1.md`).

The central register should not contain unnecessary sensitive personal information. Identity information is linked via Participant ID only.

## Register Fields

| Field | Description |
|---|---|
| Participant ID | Unique identifier assigned by pilot coordinator |
| Category | Participant category code (above) |
| Recruitment source | Channel through which participant was identified |
| Eligibility status | ELIGIBLE / NOT_YET_ELIGIBLE / UNABLE_TO_VERIFY / CONFLICT / PENDING |
| Consent status | NOT_YET_SIGNED / PART_A_SIGNED / PART_A_AND_B_SIGNED / WITHDRAWN |
| Conflict status | NO_CONFLICT / DECLARED_MANAGEABLE / RECUSAL_REQUIRED / PENDING |
| Assessor assignment | Participant ID of assigned assessor(s) (candidates only) |
| Participation status | NOT_STARTED / ACTIVE / COMPLETED / PAUSED / WITHDRAWN |
| Withdrawal status | NOT_WITHDRAWN / WITHDRAWN_DATE / REASON_CODE |
| Evidence status | NOT_SUBMITTED / SUBMITTED / VERIFIED / GAP_IDENTIFIED / INCOMPLETE |
| Outcome status | PENDING / COMPLETE / UNDER_REVIEW / NOT_APPLICABLE |
| Follow-up | Any required follow-up action |
| Publication permission | NO_CONSENT / PART_B_SIGNED / WITHDRAWN |

---

## Eligibility Status Codes

| Code | Meaning |
|---|---|
| ELIGIBLE | Applicant meets inclusion criteria |
| NOT_YET_ELIGIBLE | Does not currently meet eligibility threshold |
| UNABLE_TO_VERIFY | Eligibility evidence cannot be verified |
| CONFLICT | Unmanageable conflict prevents participation |
| PENDING | Eligibility review not yet complete |

---

## Withdrawal Reason Codes

| Code | Meaning |
|---|---|
| VOLUNTARY | Participant chose to withdraw — no specific reason required |
| AVAILABILITY | Participant unable to continue due to availability |
| HEALTH | Participant unable to continue for health reasons |
| CONFLICT_IDENTIFIED | Conflict identified after participation commenced |
| OTHER_RECORDED | Other reason, recorded separately in Decision Register |

Withdrawal is not treated as failure and must not be characterised as such.
