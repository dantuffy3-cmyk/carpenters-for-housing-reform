## Purpose of This Folder

This folder contains the External Validation & Reviewer Pack for the Advanced Residential Carpentry reform framework.

External validation prepares the existing framework for structured independent challenge before any live candidate recruitment. Its purpose is to expose the framework to credible independent scrutiny, record material objections, identify evidence gaps and determine whether the framework should be retained, revised, narrowed, further tested or rejected.

This is not an endorsement exercise.

No outreach to reviewers, government or external parties occurs as part of this sprint.

---

## What External Validation Is

External validation does not mean reviewers agree with the proposal.

External validation means the framework has been exposed to credible independent challenge and material objections have been recorded, investigated and responded to transparently.
