# External Validation Readiness Checklist — Advanced Residential Carpentry v0.1

**Status:** Working Draft — to be completed before any reviewer is approached.
**Prepared by:** Carpenters for Housing Reform Victoria
**Version:** 0.1
**Date:** August 2026

---

## Purpose

Before any external reviewer is approached, the initiative must confirm that the external validation architecture is complete and that the framework being reviewed is consistent, current and stable.

This checklist must be completed and retained. Incomplete items must be resolved or recorded as known gaps with a documented reason for proceeding.

No outreach to reviewers may commence until this checklist has been reviewed by the Initiative Lead and any incomplete items have been assessed.

---

## Checklist

### Framework Consistency

- [ ] The canonical practitioner-function hierarchy (public-interest problem → practitioner function → capability → assessment → calibration → governed pilot → public-interest evaluation → statutory vehicle, if any) is documented and internally consistent across the governing source documents.

- [ ] The capability-first / statutory-vehicle-second logic is explicit in the framework documents and is not contradicted by any document in the repository.

- [ ] All six implementation options (A–F) remain open in the framework documents. No document predetermines a single outcome.

- [ ] **No formal recognition / status quo (Option E)** is stated explicitly as a legitimate outcome in the framework documents.

---

### Reviewer Pack Readiness

- [ ] The External Validation One-Page Summary is current and does not contain promotional or endorsement language.

- [ ] The External Reviewer Pack is current and consistent with the governed source documents.

- [ ] The External Reviewer Question Set invites criticism and does not direct reviewers toward support.

- [ ] The External Reviewer Independence Protocol is complete and accurately describes the controls on Dan Sonsie's role during review.

---

### Capability Domains

- [ ] The seven capability domains in the External Reviewer Pack match the seven domains in `docs/advanced-residential-carpentry-capability-model-v1.md`.

- [ ] Structural Understanding is clearly bounded from engineering design authority in all documents presented to reviewers.

- [ ] Professional Judgement is positioned as the integrating capability domain.

---

### Assessment Scoring

- [ ] The 0–4 scoring rubric described in the External Reviewer Pack matches the scoring rubric in the governed assessment framework.

- [ ] The principle that critical safety and boundary failures cannot be averaged away is explicitly stated.

- [ ] The principle that unknown information cannot improve an outcome is explicitly stated.

- [ ] The principle that stopping, investigating, referring or escalating may demonstrate advanced competence is explicitly stated.

---

### Calibration Controls

- [ ] The assessor calibration architecture described in the External Reviewer Pack is consistent with `docs/advanced-carpentry-assessor-calibration-pack-v0.1.md`.

- [ ] Material disagreement categories are identified and consistent with the calibration pack.

- [ ] The control that Dan Sonsie does not automatically assess candidates is documented.

---

### Pilot Governance

- [ ] The pilot governance summary in the External Reviewer Pack is consistent with `docs/advanced-carpentry-pilot-governance-plan-v0.1.md`.

- [ ] Voluntary participation is explicitly stated.

- [ ] Adverse and null findings retention is explicitly stated.

- [ ] Recruitment independence controls are documented.

- [ ] Consent and publication consent separation is documented.

---

### Process Controls

- [ ] The External Reviewer Conflict Declaration template is complete.

- [ ] The External Reviewer Feedback Record template is complete.

- [ ] The External Validation Evidence Register template is complete.

- [ ] The External Validation Success Criteria document is complete, including the DO_NOT_PROCEED_TO_PILOT_AT_THIS_STAGE outcome.

- [ ] The External Reviewer Category Framework is complete.

- [ ] The External Validation Process document is complete.

- [ ] The External Reviewer Independence Protocol is complete.

- [ ] The Control Traceability Matrix has been completed to confirm that new validation documents are traceable to existing governed source documents.

---

### Privacy and Data Handling

- [ ] The privacy controls applicable to reviewer identity and reviewer findings are identified and consistent with `docs/pilot-privacy-and-data-handling-plan-v0.1.md`.

- [ ] De-identification and anonymous review options are documented.

- [ ] Publication consent separation is in place.

---

### Adverse Findings

- [ ] The adverse findings retention control is documented in the Evidence Register.

- [ ] No document in the external validation pack contains language that could be used to suppress, disclaim or reweight adverse findings without documented reasoning.

---

### Government Endorsement

- [ ] No document in the external validation pack implies that government has endorsed the project, the framework or any implementation option.

- [ ] The capability classification's limitations (no registration, no licence, no builder authority, no engineering authority etc.) are clearly stated.

---

### Recruitment

- [ ] No recruitment of pilot candidates has commenced.

- [ ] No outreach to reviewers has commenced as part of this sprint.
