# External Validation Control Traceability Matrix — Advanced Residential Carpentry v0.1

**Status:** Working Draft.
**Prepared by:** Carpenters for Housing Reform Victoria
**Version:** 0.1
**Date:** August 2026

---

## Purpose

This matrix maps each external validation control back to its source in the existing governed architecture.

Its purpose is to confirm that the external validation pack integrates and is consistent with the existing governed documents — not that it silently replaces them.

Where a conflict is identified, the detailed governed source document remains controlling unless a deliberate governance decision to supersede it is documented in the Decision Register.

---

## How to Read This Matrix

| Field | Meaning |
|---|---|
| Control ID | A unique identifier for this validation control |
| Validation Requirement | What the external validation pack requires |
| Existing Source Document | The governed document from which this requirement derives or with which it must be consistent |
| Relevant Section / Control | The specific section or control in the source document |
| New Validation Document | The external validation document that implements or references this requirement |
| New Policy Introduced | Whether the validation document introduces a new policy position not present in the source document |
| Unresolved Issue | Whether a gap, conflict or unresolved matter exists |

## Summary of New Governance Introduced

The following controls are introduced by the external validation pack that do not have a direct prior source document. Each is consistent with the existing governed architecture.

| New Control | Rationale |
|---|---|
| External validation process (TRM-023) | A new process stage prior to pilot preparation. Consistent with governed hierarchy but not previously documented. |
| Feedback classification system (TRM-025) | Operational vocabulary for classifying reviewer findings. Consistent with evidence governance principles. |
| Validation outcome vocabulary (TRM-026) | Operational vocabulary for recording validation conclusions. Consistent with decision hierarchy. |

No new policy position is introduced that contradicts the existing governed architecture.

## Conflicts Identified

None identified.

If a conflict is identified after this matrix is completed, it must be recorded here and resolved through a documented governance decision before external validation proceeds.
