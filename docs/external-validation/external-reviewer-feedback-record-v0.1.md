# External Reviewer Feedback Record — Advanced Residential Carpentry v0.1

**Status:** Working Draft — template for recording material reviewer comments.
**Prepared by:** Carpenters for Housing Reform Victoria
**Version:** 0.1
**Date:** August 2026

---

## Purpose

This record captures each material comment made by an external reviewer, the initiative's response, and the action or decision taken.

Reviewer support must NOT be treated as validation by itself.

Adverse findings, null findings and unresolved issues must be retained and must not be deleted.

---

## Feedback Classification Definitions

| Classification | Meaning |
|---|---|
| SUPPORTS | Reviewer considers this element of the framework adequate or well-designed |
| CHALLENGES | Reviewer questions the adequacy, accuracy or appropriateness of this element |
| IDENTIFIES_GAP | Reviewer identifies an issue the framework does not currently address |
| REQUIRES_EVIDENCE | Reviewer considers an element unsubstantiated and requires supporting evidence |
| SUGGESTS_REFINEMENT | Reviewer considers the element adequate but improvable |
| MATERIAL_OBJECTION | Reviewer raises an objection that, if unresolved, would materially affect the framework's credibility or the decision to proceed |
| OUT_OF_SCOPE | Reviewer has raised a matter that falls outside the scope of this validation |

Reviewer support is evidence of a reviewer's opinion. It is not proof that the framework is valid or that formal recognition is required.
