Purpose

Clear operational boundaries

This matrix establishes the scope limits within which RRC practitioners can work and identifies the mandatory handoff points where builder responsibility must apply.

Operational Boundary Reference

The Scope & Handoff Matrix provides practitioners, consumers, builders, insurers and regulators with a clear operational reference for the proposed Registered Residential Carpenter pathway.

This boundary map identifies:

  • Work types and conditions within RRC scope
  • Explicit scope exclusions
  • Mandatory handoff triggers where builder responsibility must begin
  • Technical limits and constraints
  • Documentation and assurance requirements

Scope Definition

Clear definition of renovation carpentry work within the RRC pathway, with technical and practical limits.

Exclusions

Explicit work types and situations that fall outside RRC scope and require builder responsibility.

Handoff Triggers

Specific conditions and circumstances that trigger mandatory handoff to licensed builder responsibility.
