# Carpenters for Housing Reform Victoria

## Residential Renovation Capability in Victoria

An evidence-based reform initiative examining residential renovation capability, consumer protection and professional recognition within Victoria's residential building sector.

---

## Purpose

This repository contains the research, policy development, consultation material and website supporting the Carpenters for Housing Reform Victoria initiative.

The flagship project is the development of a government-quality white paper examining how advanced residential renovation capability should be recognised within Victoria's existing regulatory framework.

The project evaluates multiple policy options while maintaining the principles of consumer protection, professional accountability and regulatory integrity.

---

## Guiding Principles

• Consumer protection first

• Evidence before advocacy

• Respect existing professions

• Improve—not replace—the current regulatory system

• Recognition based on demonstrated capability
